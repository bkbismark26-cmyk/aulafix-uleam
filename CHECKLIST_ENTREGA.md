# Checklist de entrega AulaFix ULEAM

## Configuración
- [ ] Node.js instalado
- [ ] Firebase CLI instalado
- [ ] Proyecto Firebase creado
- [ ] Authentication Email/Password activado
- [ ] Firestore creado en modo producción
- [ ] firebase-config.js actualizado
- [ ] .firebaserc actualizado
- [ ] Reglas Firestore desplegadas
- [ ] Cloudinary configurado si se usarán imágenes

## Pruebas obligatorias
- [ ] Registrar usuario
- [ ] Iniciar/cerrar sesión
- [ ] Crear reporte
- [ ] Ver mis reportes
- [ ] Convertir cuenta a administrador
- [ ] Crear/registrar otra cuenta y convertirla a técnico
- [ ] Admin marca reporte como revisado
- [ ] Admin asigna técnico
- [ ] Técnico inicia trabajo
- [ ] Técnico sube evidencia y soluciona
- [ ] Admin cierra el reporte
- [ ] Revisar historial
- [ ] Revisar comentarios
- [ ] Intentar entrar a panel admin con usuario normal (debe impedirse)
- [ ] Intentar saltar estados (debe impedirse)

## Evidencias para presentación
- [ ] Captura de login
- [ ] Captura de registro
- [ ] Captura de nuevo reporte
- [ ] Captura de Firestore
- [ ] Captura de panel admin
- [ ] Captura de asignación de técnico
- [ ] Captura de panel técnico
- [ ] Captura de evidencia de solución
- [ ] Captura de historial
- [ ] Captura del sitio publicado
- [ ] Captura del repositorio GitHub y commits

## Personalización para que sea trabajo del grupo
- [ ] Cambiar nombre/logo/colores si desean
- [ ] Agregar al menos 2 categorías propias
- [ ] Agregar al menos 1 mejora funcional propia
- [ ] Probar con datos creados por el grupo
- [ ] Escribir conclusiones con sus propias palabras
- [ ] Cada integrante entiende una parte del código
- [ ] Registrar errores encontrados y cómo los solucionaron
